# daraghmeh.me

Personal portfolio for Mohammad Daraghmeh — Senior Technical Program Manager,
AI/ML and big-data infrastructure.

Live at **[daraghmeh.me](https://daraghmeh.me/)**.

## Build

None. `index.html` is a single self-contained file — all CSS and JS are inline,
there is no framework, no bundler, and no dependency to install. Edit it and push.

## Layout

| Path | What it is |
|---|---|
| `index.html` | The entire site |
| `img/portrait.jpg` | Hero portrait |
| `img/experience/` | Employer logos used as timeline badges |
| `document/` | Résumé PDF and the Project R.I.C.K. capstone papers |
| `CNAME` | Custom domain for GitHub Pages (`daraghmeh.me`) |
| `robots.txt`, `sitemap.xml` | Search engine directives |

## Deploying

The `gh-pages` branch is served directly by GitHub Pages. Pushing to it publishes.

## Notes

- Canonical URL is the non-www form; `www.daraghmeh.me` 301s to it.
- The contact form posts to Web3Forms. Its access key is public by design.
- Analytics is Cloudflare Web Analytics — cookieless, no cross-site tracking.
